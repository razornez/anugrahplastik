# Release candidate 2026-10-13

Baseline repository: `608bf4f` (`fix: use official logo for social previews`).
The active production SHA must be recorded again from the VPS immediately
before cutover and compared with this baseline.

## Application changes

- Consolidated responsive Back Office styling, compact mobile typography,
  eight-pixel page gutters, accessible interaction states, loading and error
  states, and visual regression coverage from 320 px through desktop.
- Flattened transaction workspaces and made all six transaction steps use the
  same mobile navigation, section insets, form density, and surface rules.
- Improved dashboard, Growth, competitors, Finance, Prospects, Marketing,
  Insights, Content, master data, templates, Email CS, login, loading, and
  error views.
- Added private 3D source management: 100 MB uploads, optional business
  relations, metadata/source replacement, permanent guarded deletion,
  checksum-bound derived GLB previews, mobile viewer controls, and storage
  quota accounting.
- Added cursor pagination for landing media and human-readable analytics
  health durations.

## Integration changes

- Email CS and Google Ads can be scheduled independently through the existing
  authenticated sync endpoint.
- Separate systemd timers isolate five-minute mailbox synchronization from the
  fifteen-minute Google Ads retry cadence.
- Google Ads keeps its initial manual verification gate, then automatically
  renews a stale read-only probe. Daily reports use an atomic claim and at most
  three attempts separated by fifteen minutes.
- Integration health and scheduler heartbeats are shown separately in the
  Back Office. Provider logs retain safe status codes only.

## Schema

- Migration `0042_cuddly_wiccan.sql` adds derived-preview metadata and
  `updated_at` to `product_design_files` only. It contains no seed, fixture, or
  business-data update.

## Verified locally

- Unit/integration suite: 201 tests, 200 passed, one optional database test
  skipped in the default suite; the optional PostgreSQL Google Ads test passed
  separately (8/8).
- Typecheck, ESLint, Prettier check, and Next.js production build passed.
- Migration ran twice successfully against a disposable isolated PostgreSQL
  database and exposed all six new columns.
- Playwright covered the authenticated admin routes at 320, 375, 390, 430,
  768, landscape, and desktop sizes. The dashboard baseline includes the new
  provider-health warning.

## Explicit exclusions

- Local databases, dumps, private storage, backups, environment files,
  credentials, logs, screenshots, Playwright output, and other QA artifacts.
- Seed/demo/QA commands and their output.
- Root-level shared-hosting workflow, brainstorming material, competitor
  profiles, and other files unrelated to the VPS application release.

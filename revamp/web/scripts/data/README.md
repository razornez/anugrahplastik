# Katalog wilayah Indonesia

`indonesia-regions-493bd1.json.gz` adalah snapshot referensi, bukan fixture atau
data pelanggan. Snapshot dibuat oleh `node scripts/build-region-snapshot.mjs`
dari revisi tetap `cahyadsn/wilayah` (`5d450cc`) dan
`cahyadsn/wilayah_kodepos` (`ba84971`), mengikuti sumber yang dipakai
`emsifa/api-wilayah-indonesia` pada revisi `493bd1c`.

Importer production membaca berkas lokal ini; tidak ada permintaan jaringan
saat runtime. Sumber-sumber tersebut berlisensi MIT. Commit sumber lengkap
tercatat di skrip pembuat dan di metadata snapshot.
